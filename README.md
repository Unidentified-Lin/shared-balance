# 一起生活 Together

純前端家庭分攤試算器。直接開啟 `dist/index.html`，或在此目錄執行 `python -m http.server 4173 --directory dist` 後開啟 http://localhost:4173。

- A、B 月收入與最低保留生活費，分攤比例滑桿與百分比輸入。
- 支出明細集中於對話框，長清單獨立捲動。
- 加薪模擬比較：依新收入重算，或維持原分攤比例。
- 資料只存於瀏覽器 localStorage；不同裝置不會同步。外部字型失敗時使用系統字型。
- 金額使用非負整數元；每筆輸入上限十億元。A 支出四捨五入，B 承接尾差。最低生活費未啟用時仍不允許負結餘。
- 無法同時滿足生活費與支出時不產生虛假分配，顯示缺口。收入均為零且沒有支出時收入比例顯示 50:50 作為中性預設。
- 主滑桿始終調整原始計畫，加薪結果以差額及對比比例呈現；「依收入分配」會持續跟隨收入，手動拖動後改為自訂比例。

驗證：`node model.test.cjs`。計算模型與畫面分離，測試涵蓋分攤加總、保留生活費、零收入與不可行條件。
